# Старт работы

Общие договорённости, распределение задач и правила PR: **[руководство команды](docs/team-guide.md)**.

- `Assets/Game/` — пять модулей Unity с отдельными владельцами.
- `Packages/`, `ProjectSettings/`, `Assets/Settings/` — уже добавленная конфигурация Unity и URP; владелец — участник №1.

Для первого открытия:

1. Установить **Unity 6000.6.5f1** через Unity Hub — версия закреплена в `ProjectSettings/ProjectVersion.txt`.
2. В Hub добавить **корень этого репозитория** как существующий проект. Новый проект создавать не нужно.
3. Дождаться восстановления пакетов и импорта, открыть `Assets/Scenes/SampleScene.unity`, проверить Console и Play Mode. Это пока шаблонная сцена с камерой, светом и Volume, без игрового процесса.
4. Найти свою роль в руководстве. После слияния общего каркаса создать отдельную `feature/...` от актуальной `main` и работать в своём модуле.

Используются **URP 17.6.0** и **Input System 1.20.0**. Игровые скрипты и префабы ещё не реализованы; будущая общая сцена — `Assets/Game/Core/Scenes/Game.unity`. Перед параллельной реализацией участник №1 завершает оставшиеся шаги из раздела «Первый общий запуск» руководства. Не создавайте отдельные Unity-проекты внутри модулей.
