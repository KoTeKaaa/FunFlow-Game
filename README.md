# Tail Thief

Игра об ограблении музея для desktop. Запускай хвостатого воришку оттягиванием мыши, собирай ценности и доберись до выхода. Добыча утяжеляет мешок и сокращает дальность запуска; ловушки режут мешок или включают сигнализацию с обратным отсчётом.

## Запуск из Unity

Нужны **Unity 6000.6.5f1** и Unity Hub. Версия закреплена в `ProjectSettings/ProjectVersion.txt`; зависимости восстанавливаются из `Packages/manifest.json` и `packages-lock.json`. Проект использует URP 17.6.0, Input System 1.20.0 и uGUI.

1. Получить репозиторий и добавить его корневую папку в Unity Hub как существующий проект.
2. Открыть его в Unity 6000.6.5f1 и дождаться восстановления пакетов и импорта ассетов.
3. Открыть `Assets/Game/Presentation/Scenes/MainMenu.unity` и нажать Play. Главное меню также назначено стартовой сценой Play Mode.
4. Нажать «Играть» и выбрать уровень. Все три уровня доступны независимо.

`SampleScene` и Sandbox-сцены предназначены для разработки. Для обычного запуска используйте MainMenu; локальные `goal.md`, `todo.md`, `AGENTS.md` и `prototype/` не требуются.

## Управление

| Действие | Управление |
| --- | --- |
| Запуск воришки | Зажать левую кнопку мыши на персонаже, оттянуть и отпустить |
| Сила запуска | Чем дальше оттягивание, тем сильнее запуск |
| Новый запуск | После остановки персонажа |
| Пауза / продолжение | Esc; в паузе доступны рестарт, настройки и главное меню |
| Выбор в меню | Мышь или клавиши стрелок; Enter подтверждает |
| Старт с обучающей карточки | Кнопка «Начать» или Enter |
| Повтор после результата | Кнопка «Переиграть уровень» или R |
| Следующий уровень после победы | Кнопка «Следующий уровень» или N |
| Главное меню после последнего уровня | Кнопка «Выход в главное меню» или N |

После победы или поражения можно выйти в главное меню. На последнем уровне кнопка выхода не дублируется. Запуск направлен вперёд; стены отражают движение. Мешок можно потерять частично, попав в режущую ловушку. Повторная сигнализация не продлевает таймер. Выход до истечения времени завершает попытку победой.

## Уровни и результат

| Уровень | Название | Сцена |
| --- | --- | --- |
| 1 | Золотой след | `Assets/Game/Core/Scenes/Game.unity` |
| 2 | Тихая добыча | `Assets/Game/Core/Scenes/Game_Level2.unity` |
| 3 | На грани тревоги | `Assets/Game/Core/Scenes/Game_Level3.unity` |

Каждая попытка самостоятельна. Результат показывает сохранённую добычу текущего уровня; история прохождений и прогресс между сессиями не сохраняются. Громкость музыки и эффектов сохраняется локально. Музыка меняется между меню, обычной игрой и тревогой; ползунки сразу влияют на громкость.

## Проверки

В Unity откройте `Window → General → Test Runner`. Основной набор расположен в EditMode и включает интеграционные тесты с входом в Play Mode. Для полного прогона через подключённый Unity CLI/Pipeline, включая Explicit-тесты:

```sh
unity command run_tests --caller plugin --skill unity-cli --format json --mode editor --async_tests true --include_explicit true
unity command test_status --caller plugin --skill unity-cli --format json
```

Проверяйте статус до `completed`. Последний полный прогон: **118/118 passed**, без пропусков. Результаты и границы проверки приведены в [подготовке к сдаче](docs/release-check.md).

Валидатор уровней: `Tools → FunFlow → Validate All Game Levels`. Проверка меню в Play Mode: `Game → Check Main Menu in Play Mode`.

## Структура и развитие

- `Assets/Game/Core/` — состояние попытки, таймер, камера, контракты и интеграция.
- `Assets/Game/Player/` — ввод, запуск, движение и предсказание пути.
- `Assets/Game/Loot/` — добыча, мешок и витрины.
- `Assets/Game/Level/` — окружение, ловушки, охранник и выход.
- `Assets/Game/Presentation/` — HUD, меню, музыка и эффекты.

Новые уровни создаются из игровых сцен с общими префабами. Подключение предметов, ловушек и выхода, таймер каждого уровня и каталог описаны в [руководстве левел-дизайнера](docs/level-setup.md). Баланс — в [balance.md](docs/balance.md), меню — в [main-menu.md](docs/main-menu.md), источники и лицензии иконок — в [ui-icons.md](docs/ui-icons.md). Договорённости участников — в [team-guide.md](docs/team-guide.md).

## Сборки

В списке сцен сборки первой стоит MainMenu, затем три игровые сцены. Исполняемые сборки Windows, Linux и macOS готовятся отдельно; успешный прогон Editor-тестов не подтверждает запуск на этих платформах. При передаче Unity-проекта нужны `Assets`, `Packages` и `ProjectSettings` с `.meta`; кэш `Library`, `Temp` и локальные файлы восстановления не включаются.
