# Арт-дирекшн по концепту — «Музейный вор»

Цель — приблизиться к концепту простыми средствами Unity: ProBuilder-геометрия, материалы URP Lit, свет и
post-processing. Сложные модели не нужны (жюри: «сложность графики сама по себе не даёт преимущества»).
Главное — цельный стиль и читаемость объектов.

## 1. Что даёт 80% результата (делать в этом порядке)
1. **Свет и пост-обработка** — тёмная сцена + тёплые прожекторы над витринами + Bloom на золоте. Это и есть «настроение» концепта.
2. **Палитра материалов** — тёмный сланцевый пол, бордовые стены/ковёр, золото, бирюзовый выход.
3. **Камера** — перспектива, наклон ~45–50°, коридор идёт по диагонали из левого-нижнего в правый-верхний угол.
4. **HUD** — тёмные плашки с бронзовой рамкой, крупные золотые цифры, красная плашка тревоги.
5. **Пропсы** — витрины, постаменты, скамейки, колонны, картины на стенах (всё из кубов/цилиндров).

## 3. Свет и пост-обработка (URP)
- Directional Light: слабый, холодный (`#8090B0`, intensity ~0.3) — только чтобы не было черноты.
- Ambient (Lighting → Environment): тёмно-синий `#1A1E2A`.
- Над каждой витриной/экспонатом — **Spot Light** тёплый `#FFC27A`, узкий конус, тени Soft. Это главный приём концепта.
- У выхода — бирюзовый Point Light.
- Volume (Global): **Bloom** (threshold ~1, intensity ~0.6), **Vignette** 0.3, **Color Adjustments** (contrast +10,
  saturation +10), **Tonemapping** ACES. При тревоге — Vignette краснеет и пульсирует (это зона HUD/эффектов).

## 4. Объекты
- **Вор** — золотой шар (как сейчас), мешок на верёвке позади (в концепте мешок привязан вплотную — решить командой).
- **Монеты** — стоящие вертикально золотые диски (Cylinder, scale ~0.6×0.08×0.6, повернуть на 90°), медленно вращаются
  и покачиваются; «+100» всплывает при подборе.
- **Витрины с экспонатами** — постамент (куб) + стеклянный куб (URP Lit Transparent, альфа ~0.2, Smoothness 0.95) +
  экспонат внутри (ваза/бюст/кубок из примитивов) + табличка.
- **Препятствия** — скамейки (бордовое сиденье + тёмные ножки), колонны, кадки с растениями.
- **Сигнальная плита** — красный квадрат с тёмной рамкой, слегка утоплен в пол, пульсирующая Emission.
- **Лезвия** — тёмная решётка в полу, из неё торчат наклонённые стальные пластины.
- **Стены** — тёмные, с бордовыми вертикальными панно и «картинами» (плоские quad'ы с рамой).

## 5. HUD (как в концепте)
- Слева сверху: «ДОБЫЧА» — иконка мешка + крупное золотое число; под ним «ТЯЖЕСТЬ %» с полоской.
- Сверху по центру: «ДО ВЫХОДА N м» с иконкой двери.
- Справа сверху: красная плашка «ТРЕВОГА 00:42» с иконкой сирены (появляется при тревоге, до неё — «Тихо»).
- Снизу по центру: подсказка «Зажми • оттяни • отпусти» с иконкой мыши (скрывать после первого запуска).
- Шрифт с кириллицей, жирный, слегка «игровой» (например, Rubik / Russo One — лицензия OFL, можно в публичный репо).
