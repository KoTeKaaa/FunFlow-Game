# Создание и проверка уровня

1. Меняйте геометрию и расстановку в `MuseumLevel N.prefab`. Размещайте префабы из `Assets/Game/Level/Prefabs/Elements/` без добавления второго LootItem или ручных ссылок на Core/Loot.
2. Для игровой сцены копируйте одну из `Assets/Game/Core/Scenes/Game*.unity` и заменяйте экземпляр MuseumLevel. Сохраняйте GameRoot, Player, LootSet, камеру и HUD: это общая точка сборки, которую предоставляет №1. Один префаб геометрии без этих модулей не является полной игровой сценой.
3. Монеты, сигнализация, резаки, витрины и выход находят единственный активный источник в своей сцене в Start. Поиск не выполняется каждый кадр и не захватывает другую загруженную сцену. Старые явно назначенные ссылки поддерживаются.
4. Резак реагирует на слой Bag. Коллайдер мешка должен быть связан с Rigidbody; переключать резак на Player не требуется. Коллайдер монеты находится на её неподвижном корне; CoinSpin управляет только визуалом.
5. Выполните `Tools/FunFlow/Validate Current Level` в Prefab Mode или в игровой сцене. Префаб проверяется без требования иметь Core внутри. `Validate All Game Levels` проверяет включённые Game-сцены из Build Settings через временные preview-сцены, без сохранения или замены открытой сцены. Ошибки показываются в Console со ссылкой на объект.
6. Добавьте новую сцену в Build Settings и LevelSequence. Проверьте Play, сбор монеты, порез мешка, тревогу, выход и Restart.

## Подсветка и охранники

- Подсветка следует за видимой частью прицела и текущими коллайдерами предметов. Экземпляры монет, витрин, ловушек и Guard подключаются автоматически, в том числе добавленные во время игры. Материалы, коллайдеры и цены предметов подсветка не изменяет.
- Новый тип интерактивного предмета должен реализовать `IPathHighlightTarget` в своём игровом компоненте и иметь MeshFilter/MeshRenderer в своей иерархии. Это однократная настройка разработчиком префаба; левел дизайнеру ссылки на Player не нужны.
- Используйте `Assets/Game/Level/Prefabs/Guard.prefab`: источник Core можно оставить пустым, охранник находит единственный активный IRunSession в собственной сцене. Валидатор проверяет голову, материал конуса, solid-коллайдер, слой Obstacle, маски обнаружения и параметры зрения/поворота.
- Тело охранника обрывает прицел и подсвечивается красным; конус остаётся отдельной зоной зрения и не участвует в выборе предметов подсветки. Это прогноз движения, а не обещание безопасного прохода: охранник может повернуться после запуска. Стандартный пунктир на высоте 0,06 м находится выше конуса на 0,03 м; при изменении высоты конуса сохраняйте этот порядок.
- Генератор тестовой трассы автоматически заполняет готовые префабы, сохраняет их исходную высоту и проверяет результат валидатором. В существующих уровнях расстановка не меняется.

## Баланс

- Базовая монета: 50; базовая витрина: 200. Значения отдельных предметов меняйте в префабе уровня, а не только на экземпляре в Game.
- В MuseumLevel 1 сохранены прежние цены: пять исходных ранних монет по 50, три по 75, три по 100; витрины 200/300. Три дополнительные монеты PR #33 наследуют 50. Поэтому доступная сумма выросла с 1275 до 1425: сохранение цен не сохраняет общую сумму при добавлении предметов.
- Другие уровни наследуют базовые цены; их расстановка и количество предметов отличаются, поэтому прежние замеры времени первого уровня не подтверждают их баланс.
- Общий GameConfig сохранён: скорость 7,6, замедление 4, множитель полного мешка 0,5, полная тяжесть от 1000; тревога минимум 60 с, дополнительно 1,2 с на метр оставшегося пути по +X.
- Если Alarm Exit в RunSession не назначен, Core автоматически определяет единственный активный выход. Для длинных уровней вручную переподключать этот параметр не нужно.
