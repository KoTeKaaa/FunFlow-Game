Проверки выполнялись в текущем Unity Editor на Linux; запуск на другом компьютере и платформенные сборки ещё не проверены.

## Состав передачи

- Репозиторий с `Assets`, `Packages`, `ProjectSettings` и README; Unity 6000.6.5f1.
- Первая сцена сборки — MainMenu, затем три игровые сцены. Product Name — Tail Thief.
- Источники и атрибуция иконок: [ui-icons.md](ui-icons.md). Правила создания уровней: [level-setup.md](level-setup.md).
- Локальные документы планирования, `Library`, `Temp`, логи, `_Recovery` и личные экспериментальные изменения не входят в передаваемую версию.

Исполняемые сборки Windows, Linux и macOS будут подготовлены отдельно. После создания каждой сборки требуется проверить запуск меню, выбор уровня, управление, звук, паузу, рестарт и выход; результаты Editor-тестов не заменяют эти проверки.
